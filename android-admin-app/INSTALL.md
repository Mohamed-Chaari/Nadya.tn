# NADYA Admin — Android app install guide

Internal use only. This app is not on the Play Store — it's installed manually
("sideloaded") on each phone, once.

## What you need

- The file `NADYA-Admin-v1.apk`
- An Android phone with internet access

## Steps

1. **Send the APK to the phone.** Easiest options: WhatsApp to yourself,
   email attachment, or Google Drive → download on the phone.

2. **Open the downloaded file.** Android will show a warning like
   *"For your security, your phone is not allowed to install unknown apps
   from this source."* This is normal — it happens for any app installed
   outside the Play Store, not just this one.

3. Tap **Settings** on that warning, turn on **Allow from this source**
   (wording varies slightly by phone/Android version — Samsung, Xiaomi, and
   stock Android each phrase it a bit differently), then go back and tap
   **Install** again.

4. Tap **Install**, wait a few seconds, then **Open**.

5. The app icon **"NADYA Admin"** is now on the home screen / app drawer.
   Opening it goes straight to the admin login — full screen, no browser
   address bar.

## Notes

- This only needs to be done once per phone. After that, opening
  "NADYA Admin" from the home screen works like a normal app.
- The app needs an internet connection — it loads the live admin dashboard,
  it doesn't work fully offline.
- Log in with the same admin email/password used on the admin dashboard in
  a browser.
- If a thin browser bar briefly shows at the top instead of a fully clean
  app window the first time you open it, close and reopen the app — Android
  sometimes takes a moment to trust the app on first launch.

# Guide d'installation — Application Admin NADYA (Android)

Usage interne uniquement. Cette application n'est pas sur le Play Store —
elle s'installe manuellement une seule fois sur chaque téléphone.

## Ce qu'il faut

- Le fichier `NADYA-Admin-v1.apk`
- Un téléphone Android avec accès internet

## Étapes

1. **Envoyer l'APK sur le téléphone** (WhatsApp, e-mail, Google Drive...).
2. **Ouvrir le fichier téléchargé.** Android affiche un avertissement de
   sécurité — c'est normal pour toute application installée hors du Play
   Store.
3. Appuyer sur **Paramètres** dans cet avertissement, activer **Autoriser
   cette source**, puis revenir et appuyer de nouveau sur **Installer**.
4. Appuyer sur **Installer**, puis **Ouvrir**.
5. L'icône **"NADYA Admin"** apparaît sur l'écran d'accueil. En l'ouvrant,
   on arrive directement sur l'écran de connexion admin, en plein écran.

## Remarques

- Cette procédure ne se fait qu'une seule fois par téléphone.
- L'application nécessite une connexion internet.
- Se connecter avec le même e-mail/mot de passe admin que sur le tableau de
  bord dans un navigateur.
